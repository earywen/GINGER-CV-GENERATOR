# Ginger Burgeap CV Generator 2026

Générateur officiel de CV pour les collaborateurs Ginger Burgeap (formats 1 à 2 pages, FR et EN).

## Fonctionnalités
- Extraction multi-formats (PDF, Word DOCX, PowerPoint PPTX, Markdown, Texte).
- Structuration et traduction bilingue miroir avec le CLI `agy` (Gemini 3.8 Flash via OAuth Google Pro).
- Cadrage portrait studio buste avec calcul de marge supérieure naturelle (headroom).
- Moteur de rendu PDF haute fidélité conforme à la charte graphique 2026 (WeasyPrint).
- Interface interactive avec prévisualisation en direct, recadrage photo et export ZIP.

## Démarrage rapide
```bash
# Lancement direct du serveur
python3 serve.py
```
Le serveur écoute sur http://localhost:8085.
